## 🎉 v0.4.5

- 🤖 **GLM-4.7** — 高性价比Thinking Mode，只需API密钥
- 🖼️ **图像工具** — 文本模型也可通过Caret账户使用Nano Banana生成图像 / Gemini Flash分析
- 📄 **文档工具** — HWP, PDF, DOCX, PPTX跨平台支持
- ☀️ **Upstage** — 韩国独立AI基础模型提供商，Solar Pro/Mini支持
- 🧩 **Skills/Hooks** — 定义项目专属AI技能
- 📁 **双目录** — AI用(.agents/)和人用(.users/)上下文分离
- 🖼️ **图像发送开关** — 通过@提及设置图像文件发送

## ☁️ Caret附加模型

Cline不支持的模型可在Caret中使用。

- **Z.AI** GLM-4.7 (Thinking Mode)
- **Naver Cloud** HyperCLOVA X
- **Upstage** Solar Pro/Mini
- **BizRouter** 多模型路由

---

## 🛠️ 图像/文档工具

即使是纯文本模型也可通过Caret账户使用。

- **generate_image** — 图像生成 (Nano Banana)
- **analyze_image** — 图像分析 (Gemini)
- **read_document** — HWP, PDF, DOCX, PPTX读取
