## 🎉 v0.4.5

- 🤖 **GLM-4.7** — 가성비 좋은 Thinking Mode, API 키만으로 사용
- 🖼️ **이미지 도구** — 텍스트 모델도 Caret 계정의 나노바나나 이미지 생성/ 제미나이 플래시 이용 분석
- 📄 **문서 도구** — HWP, PDF, DOCX, PPTX 크로스플랫폼 지원
- ☀️ **Upstage** — 한국 독자 AI 파운데이션 모델을 만든 업스테이지 모델 Solar Pro/Mini 지원
- 🧩 **Skills/Hooks** — 프로젝트별 AI 스킬 정의
- 📁 **이중 디렉토리** — AI용(.agents/)과 사람용(.users/) 컨텍스트 분리
- 🖼️ **이미지 전송 토글** — @멘션으로 이미지 파일 전송 여부 설정

## ☁️ Caret 추가 모델

Cline에서 지원하지 않는 모델을 Caret에서 사용할 수 있습니다.

- **Z.AI** GLM-4.7 (Thinking Mode)
- **Naver Cloud** HyperCLOVA X
- **Upstage** Solar Pro/Mini
- **BizRouter** 다중 모델 라우팅

---

## 🛠️ 이미지/문서 도구

텍스트 전용 모델에서도 Caret 계정으로 사용 가능합니다.

- **generate_image** — 이미지 생성 (Nano Banana)
- **analyze_image** — 이미지 분석 (Gemini)
- **read_document** — HWP, PDF, DOCX, PPTX 읽기
