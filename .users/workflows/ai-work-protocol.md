# AI 작업 프로토콜

AI 에이전트의 작업 수행 시 따르는 단계별 프로토콜입니다.

## 작업 단계

### Phase 1: 분석
1. 사용자 요청 이해
2. 작업 범위 파악
3. 필요 문서 식별
4. 접근 방식 결정

### Phase 2: 계획
1. 작업 단계 정의
2. 필요 리소스 파악
3. 잠재적 위험 식별
4. 검증 포인트 설정

### Phase 3: 실행
1. TDD 원칙 준수
2. 단계별 구현
3. 중간 검증
4. 문서화

### Phase 4: 검증
1. 테스트 실행
2. 코드 리뷰
3. 기능 확인
4. 성능 검증

### Phase 5: 완료
1. 문서 업데이트
2. 변경 사항 정리
3. 후속 작업 식별
4. 최종 확인

## TDD 원칙

```
RED → GREEN → REFACTOR
```

1. **RED**: 실패하는 테스트 작성
2. **GREEN**: 최소 구현으로 테스트 통과
3. **REFACTOR**: 코드 품질 개선

## 문서 리뷰 체크리스트

작업 전 확인할 문서:
- [ ] 관련 아키텍처 가이드
- [ ] 기존 패턴 및 규칙
- [ ] 테스팅 가이드라인
- [ ] 수정 프로토콜

## 검증 단계

```bash
# 컴파일 확인
npm run compile

# 테스트 실행
npm run test:unit
npm run test:webview

# 타입 체크
npm run check-types
```
