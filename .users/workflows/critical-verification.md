# 비판적 검증 워크플로우

코드 리뷰 및 변경사항 검증 시 따르는 3단계 비판적 분석 방법론입니다.

## 3단계 검증

### 1단계: 기능 검증
- 요구사항 충족 여부
- 예상대로 동작하는지
- 엣지 케이스 처리

### 2단계: 품질 검증
- 코드 가독성
- 유지보수성
- 성능 고려

### 3단계: 통합 검증
- 기존 코드와 호환성
- 사이드 이펙트 없음
- 문서 일관성

## 검증 체크리스트

### 코드 검증
- [ ] 컴파일 성공
- [ ] 테스트 통과
- [ ] 타입 오류 없음
- [ ] 린트 경고 없음

### 기능 검증
- [ ] 명시된 요구사항 충족
- [ ] 엣지 케이스 처리
- [ ] 에러 핸들링 적절

### 통합 검증
- [ ] 기존 기능 손상 없음
- [ ] Cline 기능 정상
- [ ] Caret 기능 정상

## 비판적 사고 원칙

### 가정 검증
- "이게 정말 필요한가?"
- "더 간단한 방법은 없는가?"
- "부작용은 없는가?"

### 균형 잡힌 분석
- 긍정적 측면
- 개선 가능 영역
- 잠재적 위험

### 객관적 평가
- 감정 배제
- 데이터 기반
- 재현 가능한 결과

## 검증 명령어

```bash
# 기본 검증
npm run compile
npm run test:unit

# 전체 검증
npm run test:all
npm run check-types
npm run lint

# 통합 테스트
npm run test:integration
```
